# Предметы и расходники BotArena

Документ описывает подбираемые предметы, временные эффекты и параметры их баланса. Предметы создают дополнительные цели перемещения и выбор между боевой задачей и получением ресурса.

Реализованы случайное появление предметов, автоматический подбор, запас танка,
применение из JavaScript/Python и временные эффекты. Параметры ниже — стартовые
значения для балансировки. В стандартном HTTP-матче предметы включены.

Связанные правила: [режимы игры](game-modes.md), [вооружение](weapons.md), [биомы](biomes.md).

## 1. Термины

| Термин | Значение |
| --- | --- |
| Подбираемый предмет | Объект карты, доступный для получения танком |
| Мгновенный предмет | Применяет эффект непосредственно при подборе |
| Расходник | Сохраняется у танка и расходуется при активации |
| Усиление | Эффект с ограниченной длительностью или запасом действия |
| Точка появления | Место карты, в котором находится или появляется предмет |

Подбор и активация — разные события. Все пять предметов сначала попадают
в запас; стратегия выбирает момент применения командой `useItem`.
Мгновенный ремонт при подборе не используется.

## 2. Предметы и характеристики

| Предмет / значение `useItem` | Действие | Игровое применение | Параметры |
| --- | --- | --- | --- |
| Ремонтный комплект / `Repair` | Восстанавливает HP в пределах максимума | Восстановление после обмена уроном | +30 HP; при полном HP не расходуется |
| Защитный модуль / `Shield` | Поглощает входящий урон | Выход на простреливаемую позицию | 40 HP защиты на 4 с; остаточный урон переходит в HP |
| Ускоритель / `SpeedBoost` | Повышает скорость, разгон и торможение | Перехват, отход и обход | Множитель 1,4 на 3 с; поворот корпуса и башни не меняет |
| Охлаждающий модуль / `Coolant` | Ускоряет перезарядку и заряд гаусса | Усиленное давление на противника | Восстановление по 2 тика за шаг вместо 1 на 3 с; действует и на текущий цикл |
| Дымовая шашка / `Smoke` | Создаёт неподвижную область ограниченной видимости | Разрыв наблюдения и отход | Радиус 1,75 ед., длительность 3 с, обзор через дым до 2 ед. |

Щит, ремонт и ускорение не считаются новыми классами оружия. Дым не является физической стеной: блокировка движения или снарядов не входит в описанный эффект.

## 3. Подбор и применение

Предмет существует как объект карты до подбора. Его тип и доступность определяют результат взаимодействия. Использованный расходник исчезает из запаса; истёкший временный эффект прекращает действие.

Применяются следующие правила:

| Группа | Параметры |
| --- | --- |
| Подбор | Автоматически, до 0,65 ед. от центра танка включительно; через стену подобрать нельзя |
| Конкуренция | Ближайший живой танк со свободным местом; при равенстве расстояний — случайный выбор с зерном матча, без приоритета порядка ботов |
| Применение | Не более одного предмета за шаг через `useItem`; только из запаса, полученного к текущему наблюдению |
| Хранение | До двух предметов, включая одинаковые; при заполнении новый предмет остаётся на земле |
| Повторное применение | Одноимённые усиления не складывают силу; обновляют полную длительность, щит восстанавливается до 40 |
| Уничтожение танка | Запас исчезает, личные усиления прекращаются; уже созданный дым остаётся объектом мира до окончания матча или своего срока |
| Возрождение | В «Царе горы» и Deathmatch танк возвращается с пустым запасом и без личных усилений; предметы на поле и уже созданный дым сохраняются |

Разные усиления могут действовать одновременно. Команда для отсутствующего
предмета ничего не делает и не сохраняется на будущие тики. Подобранный на
текущем шаге предмет можно использовать только при следующем решении.
Если одновременно доступны несколько предметов, они обрабатываются по ID.

## 4. Размещение и доступная информация

На тике 0 размещаются три случайных предмета. Затем через случайный интервал
от 1 до 2 игровых секунд появляется один новый предмет, пока на земле
меньше шести. Подобранные предметы освобождают место на поле. Предметы на
земле не исчезают по таймеру. В конце матча новые предметы не создаются.

Позиции выбираются случайно внутри арены с отступом от стен и границ,
достаточным для поворота корпуса. Между предметами сохраняется расстояние
не меньше 0,8 ед.; рядом с танками новые предметы не появляются. Все пять
типов равновероятны; список доступных типов настраивается. На одну попытку
появления допускается до 64 проверок позиции; при отсутствии свободного
места появление пропускается и назначается следующий случайный интервал.

Сервер выбирает новое `MatchConfig.RandomSeed` перед матчем. Значение
сохраняется в `replay.randomSeed`; одинаковые конфигурация, зерно и команды
дают те же позиции, типы и сроки появления в одной версии движка.
Зерно и будущие моменты появления не передаются стратегии.

Для соревновательного формата доступ к ресурсам учитывается вместе со стартовыми позициями и геометрией карты. Равные расстояния до предмета не гарантируют равные условия: важны укрытия, прострелы и время прохода по разным поверхностям.

Предметы и дымовые облака передаются стратегии только в пределах текущей
видимости с учётом стен, тумана и дыма. Запас противника скрыт даже при его
видимости; активные усиления и щит доступны только у видимого танка.
События появления и подбора передаются зрительскому реплею, а не стратегии.

## 5. Взаимодействия и баланс

| Взаимодействие | Значение для баланса |
| --- | --- |
| Ремонт и дуэль | Неограниченное восстановление может поддерживать бесконечное избегание боя; существенны объём ресурса и интервалы появления |
| Щит и гаусс-пушка | Защита от одной мощной атаки зависит от поглощения и переноса избыточного урона; полное обнуление любого попадания не установлено |
| Ускорение и захват флага | Изменяется время доставки и возможность перехвата носителя |
| Охлаждение и гаусс-пушка | Уменьшение самой долгой перезарядки может устранить основное ограничение класса |
| Дым и миномёт | Потеря видимости не запрещает атаку по последней известной точке |
| Ускорение и биом | Результат зависит от порядка применения усиления и свойств поверхности |

Общие параметры баланса: сила и длительность эффекта, доступность ресурса, число предметов на карте, интервал повторного появления и возможность повторного подбора лидирующим участником. Ценность предмета зависит от режима, оружия и положения танка.

Порядок шага: прекращение истёкших эффектов и дыма; применение предметов;
движение; выстрелы и урон; очистка запаса уничтоженных танков; подбор живыми
танками; случайное появление; завершение матча. Ремонт и новый щит действуют
до входящего урона этого шага. Уничтоженный танк ничего не подбирает.
В «Царе горы» и Deathmatch перед новым появлением предмета проверяется завершение по
очкам; на завершающем тике новые предметы не создаются.

Щит поглощает урон всех трёх типов оружия. Например, удар гаусса на 60 HP
расходует 40 защиты и снимает 20 HP. При истощении щит сразу прекращает
действовать. Ремонт не восстанавливает щит.

Ускоритель умножает уже изменённые поверхностью максимальные скорости,
разгон и торможение на 1,4. На песке максимальная скорость вперёд равна
`3.6 × 0.75 × 1.4 = 3.78` ед./с. Истечение усиления сохраняет текущую скорость;
обычная физика тормозит до нового предела. Охлаждение ускоряет оставшийся
цикл, без его сброса; после окончания эффекта возвращается обычный темп.

Дым неподвижен и ограничивает обзор для обоих танков, если отрезок между
ними проходит внутри облака и расстояние превышает 2 ед. Касание границы
без входа не скрывает. Стены и туман сохраняют свои ограничения. Дым не
блокирует движение, пули, навесные снаряды или лучи, не меняет урон и не
открывает скрытого противника после попадания.

## 6. Наблюдение и реплей

Описание предмета для стратегии включает его идентификатор, тип, позицию и доступность в пределах разрешённой видимости. Собственный запас и активные эффекты представлены отдельными состояниями; скрытые запасы противника не выводятся из публичной информации.

Для разбора матча различаются появление, подбор, применение, начало и окончание эффекта. Реплей сохраняет фактические изменения состояния, а не восстанавливает их из визуальной анимации.

В [API стратегии](user-api.md) добавлены `items`, `smokeClouds`,
`consumableRules`, `self.inventory`, `self.activeEffects`, `self.shieldHp`
и команда `useItem`. Предмет: `{id, type, position}`; усиление:
`{type, expiresAtTick}`; облако: `{id, ownerBotId, position, radius, expiresAtTick}`.
Поле `inFog` описывает статический туман, дым передаётся отдельно.

В реплее сохраняются `ItemSpawned`, `ItemPickedUp`, `ItemUsed`,
`EffectStarted`, `EffectEnded`, `BotRepaired`, `SmokeCreated`, `SmokeExpired`.
У предметных событий есть `itemType` и при наличии объекта — `itemId`;
у ремонта `amount`, у попадания — фактические `damage` по HP и `shieldDamage`.
Отрисовка показывает предметы с символами типов, запас, эффекты, щит и дым.

## 7. Настройка и пример

Правила задаются в `MatchConfig.Consumables` (`ConsumableRules`). В карте
`Biomes` они включены, в `Classic` по умолчанию выключены. Для специальных
карт и тестов можно задать `MatchConfig.InitialItems` с фиксированными
позициями; они не передаются в публичных правилах наблюдения.

```js
function tick(state) {
  const stock = state.self.inventory;
  if (state.self.hp <= 70 && stock.includes("Repair")) {
    return { useItem: "Repair" };
  }
  if (state.enemy && stock.includes("Shield") && state.self.shieldHp === 0) {
    return { useItem: "Shield" };
  }
  return {};
}
```

В Python те же имена: `return {"useItem": "Shield"}`.
Движение, наведение и стрельба могут возвращаться в том же ответе.
